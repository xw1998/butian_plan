## 探索预算

正常服务的梦境与普通假设共用 team.db 的持久 reservation，按成员累计。CLI exploration-budget get/set 的 --member-id 配置现在写入团队台账中的成员策略；未设成员策略时使用团队默认策略。配置与审计在同一保存点提交，审计拒绝会撤销策略修改。

默认 max_cost=50、max_actions=50、max_risk=0.2、window_seconds=86400 是实现默认值，不是需求指定数字。cost_unit=declared_exploration_unit，是声明探索单位，不代表 API 账单或货币。预算不授予 OS 或工具权限。

梦境跨库启动先持久登记团队 reservation，再修改成员数据库。成员 running 更新失败会保留一次 charge；同 action 重试不会重复扣账。新增触发器故障测试验证 queued 保留、单次 charge 和重试成功。

独立 DreamRunner 使用成员本地数据库。旧成员数据库预算策略和历史 charge 的保守兼容仍需审查，不能认为本次策略统一已经完成所有升级边界。

梦境单轮参数严格拒绝 bool、小数操作数、NaN、Infinity，写入前失败。该预算材料数闸门不等于实际模型调用费用计量。

## 执行故障

停止的 PermissionError、OSError、TimeoutExpired 和非零返回码阻断重复停止尝试；异常类型和可用真实错误码透出。本轮没有重跑此前被工具权限拒绝的真实停止操作。

进程启动后持续 SQLite 故障会保留活动进程登记，并将不含输入、输出和凭据的恢复信息写入 BUTIAN_HOME/execution_recovery/。调用返回 audit_status=persistence_failed 和 recovery_record；进程未确认退出时保持 unknown。重启后列表读取恢复记录，仅向记录所属执行者显示，不能凭 PID 推断进程退出或再次停止。恢复文件保留不删除。

文件系统同样不可写、恢复记录汇入正式审计、资源容量限制及进程身份复核仍需验收。

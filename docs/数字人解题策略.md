# 数字人解题策略体系

补天计划将数字人的差异定义为可配置的解题顺序，而不是不可验证的职业人格。成员保存默认策略与版本，派活者依据任务类型、不确定性和风险进行组合；必要时可覆盖默认顺序，但必须记录触发条件、理由、决策者和实际阶段。

内置策略包括：经验复用型、模型建构型、证据审查型、实验迭代型、设计综合型、风险先行型、用户情境型和反方审计型。所有策略共同遵守目标与验收确认、事实与假设分离、证据门禁、授权边界、可逆优先、预测与观察记录及停止理由。

策略快照写入任务，实际执行阶段写入 `strategy_steps`。策略只能改变探索顺序，不能绕过证据、授权、成员隔离或把相关性直接写成因果。派活者的覆盖必须可审计，低置信任务特征不得伪造精确匹配。

策略效果需要通过固定任务集、相同模型和工具预算、重复运行与失败样本进行评估。当前实现提供策略目录、成员配置、任务编排、覆盖快照、MCP/HTTP 接口和阶段审计；不宣称任何策略已经在统计意义上优于其他策略。

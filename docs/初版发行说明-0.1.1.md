# 补天计划 0.1.1 初版

发布日期：2026-10-13。版本：0.1.1；附注标签：v0.1.1；发布分支：master。

## 使用与接入

需要 Python 3.11 或以上。克隆仓库后使用 `python -m pip install -e .` 安装。宿主 AI 使用标准 stdio MCP：命令 `python`，参数 `["-m", "butian.cli", "mcp"]`；设置 `BUTIAN_HOME` 为自己的数据目录。宿主使用自己的模型，无需 Ollama、providers.json 或补天模型配置。接入步骤见 [通用 AI 应用接入](通用AI应用接入.md)。主动 Provider 运行需另外配置对应服务。

## 本版修复

- CLI 全部入口遵守显式运行目录。
- 上下文召回报告只列最终实际传入的记忆。
- 实践、同伴验证与召回反馈拒绝虚构或失效证据；按证据内容防重复强化，有害反馈保存反证版本。
- 审核交接声明的方法使用自动进入实践、版本和技能台账；启动恢复完整或部分未入队的审核学习。
- 同伴验证通过团队持久台账和成员稳定事件 ID 恢复跨库中断；团队 SQLite 写事务串行处理跨进程重复证据。
- 来源实践准备同事务提交，失败不残留先验、假设、动作或准备记录。
- 实践验证指标拒绝 NaN 与正负无穷。

本次发布为可接入、可运行的初版，不作为全需求审计完成声明。

# 0.1.2 修复版

本版修复 0.1.1 之后发现的 MCP 协议兼容、实践证据及交接边界问题。面向支持 stdio MCP 的宿主 AI，无需 Ollama 或 providers.json。该发布不代表全部产品需求已经验收。

## 修复

- tools/call 成功响应使用标准 content/text/isError 结构，官方 MCP Python SDK 2.3.0 可以解析。
- 假设授权台账和 action 更新原子提交；成本、风险和信息增益拒绝非有限数值。
- 相同假设/成员使用稳定实践记忆，独立成功与反证累计为 candidate、warm、disputed；成员 outbox 崩溃后幂等恢复。
- 保存全部实践证据摘要，重复使用任何一份证据不能被当作新的独立实践。
- 交接必须由任务执行者在 running/review 状态按当前 revision 提交；置信度拒绝 bool、NaN、无穷和范围外数值。
- 修正旧测试的任务认领/执行者前置条件，保留新增权限门槛；覆盖旧同伴事件和缺版本恢复。

## 验证

完整回归与真实闭环证据见 [当前验收](当前闭环验收-20261013.md)。官方 SDK 握手/发现/调用、真实公网 SQLite 来源实践与后续使用/反证/重启、Playwright 单人提问恢复和团队汇总审核通过。页面使用真实 local-command 进程，不据此宣称模型智能已验证。

## 安装与接入

Python 3.11+；仓库中执行 python -m pip install -e .，初始化并配置独立 BUTIAN_HOME。MCP 客户端使用 python -m butian.cli mcp。身份认证及任务流程见 [通用 AI 接入](通用AI应用接入.md)。

## 已知边界

标准协议通过不等于所有商业客户端兼容。真实外部商业模型、跨独立业务任务长期自主成长、线上部署安全未完成全面验收。host_trusted 在宿主同账号 OS 权限下运行，应用授权台账可撤销，但不提供逐能力 OS 隔离；要求未提供隔离能力的工具被拒绝。不得将上述范围描述为全需求通过。

不导入女娲历史记忆，迁移入口保持拒绝。需求正文、批准方案、运行数据和既有未跟踪资产保留。

发布形式为 master 提交及附注标签 v0.1.2；不修改旧标签。原始验收日志在本地工作区保留，仓库报告记录结果和限制，不包含凭据。

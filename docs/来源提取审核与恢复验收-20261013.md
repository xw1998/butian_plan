## 已验证行为

- 授权抓取只保存来源快照，不再把网页首行自动注册为主张。
- 已验证来源可派发 host 提取任务，无 providers.json 或内置模型依赖。跨两个服务连接只派发一次；登记失败时任务和登记一起回滚。
- 提取结果必须是 JSON claims。每项必须有原文引用、条件、限制、预测、反证；引用不在原文时拒绝交付。空 claims 必须说明限制。
- 交付和审核重新验证来源哈希。审核前不生成主张，审核后只生成 confidence=0 的 candidate，不晋升经验。
- 审核后入库失败可在维护恢复路径继续；事务回滚不留下部分候选；恢复与重启不会重复生成主张。
- 抓取来源、字节快照、验证和抓取完成状态原子持久化；快照故障不留下部分来源，失败记录保留。
- 来源失效后，新建/幂等实践准备、prior、已授权动作启动以及观察结果均进行来源复核。
- 团队汇总写入加入 BEGIN IMMEDIATE，并在锁内复核父问题版本与全部子任务版本/状态。

# 0.1.1rc1 发布验证（2026-10-13）

这是审计修复候选版，不代表《需求计划》的全部产品验收已经完成。需求正文未修改；本报告是当前验证事实，之前的分批报告保留为历史记录，其旧待办和旧测试数不能代表本次状态。

## 修复范围

- 任务版本 CAS、提问及回答事务、租约释放和恢复路径。
- Provider 启动前后版本校验、上下文版本绑定、失败补偿版本隔离、结果发布短临界区。
- 同进程及 Windows 跨进程消费互斥；终态取消优先。
- MCP 派活者身份认证与 Provider 资源授权分离，恢复消费允许使用持久化 prompt。
- 工具启动前的执行版本守卫；宿主执行授权、撤销、取消和审计链。
- 学习 HTTP 网络请求不占共享数据库写锁；HTTP 响应在正常、异常和重定向路径显式关闭。
- 单人目标、回答问题、恢复执行页面及团队审核链。

本次最后两处缺陷有修复前失败与修复后通过的回归：HTTP 响应未关闭；任务在输出期间进入 waiting_user 后仍持久化旧输出并把旧会话记为 completed。流事件现在核验任务状态、版本和最新会话，输出写入与核验共用短锁，完成发布再次核验。

## 验证结果

最终代码全量：335 passed，1 skipped，118.62 秒。跳过项是 Windows 未取得符号链接权限的备份测试，未宣称已验证。compileall、node --check web/app.js、git diff --check 通过。

定向：学习相关 32 项通过；流式失效、任务运行、恢复、团队和上下文相关 76 项通过。

本轮此前实际验证包括：Windows 子进程与跨进程消费互斥、工具禁止启动 marker、慢 HTTP socket 不阻塞任务数据库写入，以及 Chromium 单人回答恢复和团队审核至 done。浏览器使用真实 local-command 子进程；它证明页面和运行时链，不证明模型智能或自主进化。

任务审核触发可审计候选已有定向测试；记忆实践强化、反证/版本链、工具分享试用/归档恢复、反馈修复保留稳定版本有测试。单个 API 或这些测试数量不构成真实模型驱动的完整自主进化产品验收。

# 平台接入与安装形态

补天计划的核心不是某个 AI 桌面应用的插件。推荐部署为独立的本地 Python 运行时，数据和编排由补天掌握，AI 桌面应用通过适配器接入。

## 三种接入方式

1. **OpenAI 兼容 API / Ollama**：补天直接调用模型服务，适合第一阶段自动化验证。
2. **MCP Server**：把任务查询、派活、交接、记忆检索、经验验证、证据读取和状态恢复暴露给支持 MCP 的 AI 桌面应用。桌面应用只需把本地 MCP Server 配置为工具服务器。
3. **桌面应用适配器**：对有公开插件、API 或自动化协议的应用实现会话创建、发送、流式输出、取消和原生会话跳转。能力不支持时必须降级并报告原因。

## 推荐运行形态

```text
AI 桌面应用
       │ MCP 或应用适配器
       ▼
补天本地运行时（CLI + HTTP API + SQLite）
       ├─ team.db
       ├─ members/*/memory.db
       ├─ 任务、事件、证据和恢复
       └─ Provider / 模型能力协商
```

MCP 是接入层，不是核心数据库，也不是必须依赖。没有 MCP 能力的桌面应用可通过 HTTP API、命令行或手动导入交接包使用。

## 模型配置原则

成员可以保存模型偏好，但适配器必须返回实际模型：`applied`、`fallback`、`unsupported` 或 `unknown`。不能把桌面应用的默认模型冒充为成员指定模型。父会话和子会话都保存请求模型与实际模型。

## 安装建议

当前版本先使用源码/虚拟环境运行：

```text
python -m venv .venv
.venv\\Scripts\\activate
pip install -e .
butian init
```

后续增加 `butian mcp` 入口后，再将本地 MCP Server 注册到支持 MCP 的 AI 桌面应用。补天不需要安装到每一个桌面应用内部；安装一次本地运行时，再按应用配置对应适配器即可。

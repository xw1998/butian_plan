# 补天计划的认识论与人类思考逻辑

## 1. 实践是检验真理的唯一标准

论文引用：1978 年 5 月 10 日中央党校内部刊物《理论动态》第 60 期发表《实践是检验真理的唯一标准》；5 月 11 日《光明日报》以特约评论员文章形式公开发表。文章提出，社会实践不仅是检验真理的标准，而且是唯一的标准。相关历史语境可参见中国共产党新闻网“党史上的今天”以及共产党员网对文章发表经过的整理。

在补天计划中，这句话不是一句装饰性格言，而是经验写入规则：

- 语言模型的回答、成员的直觉、权威来源和梦境推演都只能形成主张或候选假设。
- 只有在明确环境、输入、操作和验收标准下产生的可追溯实践结果，才能检验主张。
- 一次成功只能说明“在该条件下得到一次支持”，不能自动推出普遍真理。
- 反复复现、对照实验、独立成员验证和跨环境验证决定证据等级。
- 实践失败不能简单证明理论绝对错误，必须检查问题表征、条件、实现、测量和归因是否正确。

因此系统将“主张”和“证据”分离，记忆状态使用 `candidate`、`warm`、`disputed`、`verified` 等状态，拒绝把未经实践检验的回答直接写成经验。

## 2. 真理的工作定义

论文不把真理定义为“模型说得像真的”，也不把它简化成“多数人同意”。在本研究的工程范围内，真理是：

> 对对象、条件和目标作出符合实际的可检验表述，并能在明确边界内指导实践、经受重复或独立证据检验，且在反例出现时能够说明适用条件或被修正。

这个定义包含四个限定：

1. **对象限定**：主张指向什么系统、问题、数据或行为。
2. **条件限定**：适用的版本、环境、输入、权限和前置条件。
3. **可检验性**：如何操作、观察和判定支持或不支持。
4. **可修正性**：出现反例时能收窄范围、分叉版本或判定失效，而不是保护旧结论。

“真理”在系统中不等于一个永久不可变的布尔值。系统保存的是带边界、证据等级、置信度和有效期的经验证主张；越出边界时必须重新验证。

## 3. 认知的螺旋上升

认识不是简单的圆圈重复，也不是一次记忆写入后的直线积累，而是“实践—观察—解释—方法—再实践—修订”的螺旋过程。每一轮都应带来至少一种提升：

- 对象表征更准确。
- 适用条件更清晰。
- 验证成本更低。
- 方法成功率更高。
- 失败模式更完整。
- 因果解释更谨慎。
- 可迁移范围更明确。

系统把一条经验建模为版本链：`v1 → v2 → v3`。若新实践只重复旧结果，增加支持样本；若步骤更好，产生优化版本；若环境不同，形成环境分叉；若反例出现，增加限制、争议或失效版本。只有“信息和能力确实增加”时才称为螺旋上升，单纯重复调用或增加文本长度不算认知进步。

## 4. 方法论的工作定义

方法论不是一套永远正确的步骤，而是连接问题、假设、行动、观察和修订的可复用程序。一个合格的方法至少包括：

```text
问题表征 → 已知/未知 → 假设集合 → 选择验证动作
→ 执行动作 → 观察证据 → 更新假设
→ 复盘成本与风险 → 形成适用条件
```

方法论必须记录目标函数和代价，因为“成功”不只包括结果正确，还包括时间、调用量、风险、可复现性和人工负担。不同目标可能产生不同推荐方法，系统不能只按成功/失败一个维度排序。

## 5. 需要纳入的其他人类思考逻辑

### 5.1 问题表征与表征修正

人类常见错误不是不会解，而是把问题理解错。系统必须保存原始问题、重述版本、隐含假设、边界和验收标准，并允许在证据不匹配时回到表征阶段。论文指标增加“问题重述后成功率”和“错误表征识别率”。

### 5.2 目标分解与手段—目的分析

将目标拆成可观察子目标，区分必要条件、充分条件、代理指标和最终指标，防止把“日志变绿”“回答变长”“局部测试通过”误当作真正完成。

### 5.3 类比迁移与差异检测

历史经验只能提供假设。召回时必须同时列出相似点和差异点，并计算环境匹配度；若关键差异未知，降低置信度并先做低成本验证。

### 5.4 归因控制

成功可能来自方法、环境、输入、偶然性或测量偏差。系统必须区分相关性和因果性，记录替代解释、控制变量和反事实问题：“如果不采用该方法，结果是否仍会发生？”

### 5.5 反事实与干预思维

复盘不能只问“发生了什么”，还要问“改变哪个变量最可能改变结果”。反事实只能产生候选解释；只有实际干预或自然对照支持，才能升级因果信念。

### 5.6 证伪优先与异常保护

验证任务不只寻找支持证据，还要主动寻找能推翻经验的边界样本。高权重经验应定期做反例测试；发现异常时先冻结自动传播，不能为了保持成功率而删掉失败样本。

### 5.7 元认知与置信度校准

Agent 必须知道自己知道什么、依据是什么、哪里不确定。系统记录预测置信度与实际结果，计算 Brier score、校准曲线、过度自信率和未知诚实率。置信度不能仅由模型自报决定。

### 5.8 信息价值与主动学习

当多个验证动作可选时，优先选择“成本低、风险低、能最大区分假设”的动作。记录验证前后的不确定性变化，计算每次行动的信息增益，避免无目的试错。

### 5.9 停止规则与收益递减

人类会在信息足够、风险可接受或继续验证收益低于成本时停止。系统需要记录停止理由：已达到验收、证据饱和、预算耗尽、风险过高或信息增益不足。停止不等于真理，只表示当前决策足够。

### 5.10 失败归因与错误预算

失败要区分知识错误、执行错误、工具错误、环境错误、沟通错误、测量错误和随机失败。每类失败分别进入经验或教训，避免把工具故障学成“方法不可行”。

### 5.11 社会学习与异议聚合

成功成员回答、客户异议、审核意见和外部来源都属于不同证据来源。系统不能按人数投票决定真理，而应按来源独立性、证据质量、环境匹配和复现结果加权。少数异议如果具有强反例证据，必须触发复核。

### 5.12 知识、技能、经验和教训分离

- 知识：关于对象或规则的陈述。
- 技能：能执行一类操作的程序能力。
- 经验：在具体情境中行动并获得结果后形成的带条件记忆。
- 教训：失败、风险和边界中提炼出的规避规则。

四者不能混写，否则会把一篇文章中的知识误当作亲身经验，把一次操作技巧误当作普遍规律。

### 5.13 记忆重构与来源锁定

回忆不是原文回放。每次召回都必须显示来源事件、版本、环境和证据；重构后的内容覆盖当前记忆正文并生成新版本；旧版本仅保留在历史链中用于审计和回溯。没有可验证来源时只能报告“抽象相似，未找到具体经历”。

### 5.14 认知冲突与双重记账

同一经验可能在不同环境下同时有效和失效。系统保存冲突组和适用条件，不强行平均成一个模糊结论。冲突未解决时，召回结果必须并列呈现支持和反例。

### 5.15 价值、风险与伦理约束

人类决策不只追求成功率，还要考虑伤害、权限、隐私、公平和不可逆后果。系统为高风险行动设置更高证据门槛；低风险模拟可以先行，高风险真实执行必须显式授权。

## 6. 对补天系统的直接要求

上述逻辑最终必须落到数据和验收，而不能停在论文口号：

- 每条经验带问题表征、适用条件、方法、结果、替代解释和证据。
- 每次验证前记录假设与预测，验证后记录观察和偏差。
- 经验升级必须有实践事件，不允许仅靠梦境、投票或模型自评。
- 每次失败分类并保留原始证据。
- 召回结果同时展示相似点、差异点、版本、置信度和反例。
- 高风险行动有更高证据等级和人工授权要求。
- 论文实验增加校准、迁移、反事实、信息增益、停止质量和失败归因指标。

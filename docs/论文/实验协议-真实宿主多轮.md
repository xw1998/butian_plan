# 实验协议：真实宿主多轮交互（host-loop v1）

- 冻结时间：2026-11-02，`written_before_execution = true`
- 协议版本：`host-loop-v1`
- 状态：**预注册**。本文件在任何宿主作答之前写成，判据、评分口径和样本量在运行中不得修改；如需修改必须另立 `host-loop-v1.1` 并保留本文件。

## 1. 为什么要做这项实验

已有三项实验的边界：

| 实验 | 宿主是什么 | 缺什么 |
| --- | --- | --- |
| 多轮机制实验（10 种子） | 确定性求解器 `solve()` | 不是真实模型，无法说明"模型会不会条件化" |
| 端到端门槛实验（20 种子） | 同一个确定性求解器 | 机制清楚了，但宿主行为仍是脚本 |
| 同 Agent 试跑（15 条） | 当前对话里的同一个模型 | 非盲、单轮、正则关键词打分、脚本注入上下文而非工具 |

本协议补的是最后一行：**真实模型 + 真实 MCP 工具 + 多轮 + 客观判分**。

## 2. 宿主与通道

- 宿主：当前会话的真实模型（灵犀 Agent），通过 `python -m butian.cli mcp` 的 stdio JSON-RPC 与生产服务交互。
- 宿主可用的动作只有三个：
  1. `butian_memory_recall` —— 取经验（返回记忆内容、状态、证据数或空）；
  2. `butian_knowledge_source_read` —— 读已登记、已哈希校验的源文档快照；
  3. 提交答案。
- 宿主**不能写经验**：经验写回由 harness 在客观判分之后执行（`butian_evidence_record` + `butian_memory_practice`），`independent_key` 由轮次生成。写入不依赖模型自述，所以"经验可信"不是模型说了算。
- 源读取次数、召回次数由 harness 的 MCP 调用轨迹与生产服务事件共同记录，不采信模型自报。

## 3. 任务与真值

- 沿用主实验的三个任务族：`calibration`（数值换算）、`schema`（字段名随版本变化）、`tool`（端点与参数名）。
- 12 个实体 = 3 族 × 4；每族前 2 个是**稳定实体**（三版本不变），后 2 个是**漂移实体**（R2 升 v2、R3 升 v3）。
- 每题的真值由 `solve(active_rule, task)` 给出（与主实验同一函数），判分是**精确匹配**：
  - `calibration`：`|answer − truth| ≤ 1e-6`
  - `schema`：两个字段值都满足 `|Δ| ≤ 1e-9`
  - `tool`：端点字符串完全相同且参数名、参数值完全相同
- 答不出时宿主必须输出 `{"unknown": true}`，不得猜。`unknown` 记为"未完成"，不计为错误。

## 4. 轮次与经验生命周期的对应

| 轮次 | 版本状态 | 经验应处于 | 宿主应当 |
| --- | --- | --- | --- |
| R1 | 全部 v1 | 无经验 | 读源，形成候选 |
| R2 | 稳定实体仍 v1；漂移实体升 v2 | 稳定实体候选+1 次实践；漂移实体内容失配 | 稳定实体可复用/再实践；漂移实体必须读源 |
| R3 | 稳定实体仍 v1；漂移实体升 v3 | 稳定实体已通过两次独立实践（warm） | 稳定实体应复用且不读源；漂移实体必须读源 |

## 5. 预注册判据（全部冻结）

- **P1 正确率不下降**：稳定实体在 R3 的首答正确数 ≥ R1 的首答正确数。
- **P2 版本准入有效**：漂移实体在 R2、R3 上"沿用旧版本规则导致的错误"次数 = 0；且漂移实体在 R2、R3 的源读取次数 = 实体数（每个漂移实体每次必须读源）。
- **P3 复用的代价被省掉**：稳定实体在 R3 的源读取次数 ≤ 稳定实体数 × 0.5，且其正确数不低于 R1。
- **P4 经验确实形成**：R3 时，稳定实体对应的记忆状态为 `warm`；漂移实体对应记忆状态为 `candidate` 或 `disputed`（因为每次版本变更后只有一次实践）。
- **P5 行为可审计**：每题至少一次 `butian_memory_recall`；R3 稳定实体的答案若未读源，其依据必须能在召回内容中找到。

判据不成立时，按不成立报告，不做事后阈值调整。P1/P3 属于"验证有效"，P2/P4 属于"验证机制"，P5 属于"验证行为真实发生"。

## 6. 样本量与统计口径

- 规模：12 实体 × 3 轮 = 36 次作答；这是 **pilot**，不是显著性检验。
- 统计单元：轮次内的实体（同族内 2 个），不把 36 次作答当 36 个独立样本。
- 报告方式：逐题结果表 + 按轮次聚合 + 按稳定/漂移分组。**不报告 p 值**，只报告计数与差值。

## 7. 已知限制（必须在结果里重复）

1. **非盲**：宿主同时是实验设计者，知道哪一族是稳定实体、知道 R3 期望复用；这只能靠"判分客观 + 判据事前冻结"部分补偿。
2. **单宿主、单次**：没有跨模型、没有重复运行，不能外推到其他模型。
3. **任务仍是契约化合成任务**：真值来自 `solve()`，不是真实业务数据。
4. **源文档是合成的**：单个归档文本，非真实版本化文档库。
5. 本实验不测量 token 成本与延迟优势；不声称模型参数变化。

## 8. 允许的读法

- 允许："真实模型经真实工具、在多轮里确实形成了候选经验，并在第二次独立实践后复用，源读取下降而正确率保持"。
- 不允许："模型能力提升""经验自动归纳""跨模型泛化""生产环境收益"。

# 内部研究数据字典 v1

## 记录单位与条件

一次 observation 是同一宿主Agent在指定机制条件下对一个 case_id 的一次运行。B0/B1/B2 按 case_id、seed、repeat 配对；训练材料与测试案例分别保存。B0 不提供长期记忆，B1 只提供固定检索材料，B2 使用补天生产上下文、证据和经验生命周期。三组都使用相同模型能力、工具白名单和最大调用预算。

不得把本会话按顺序执行三组解释为同一宿主Agent对照：本会话已经看到任务参考和先前结果。正式比较使用同一个宿主Agent，保存每个条件的输入、真实响应、顺序和可用记忆；不要求另接模型或新建独立会话。缺失的模型版本、计费和内部推理数据记 null 与 missing_reason，不记0。

## observation 必填字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| run_id / case_id / variant | string | 唯一运行、任务编号、B0/B1/B2 |
| category | enum | repeat、transfer、conflict、source_practice、recovery |
| seed / repeat / max_model_calls | integer | 随机种子、配对重复编号、调用上限 |
| task_package_sha256 / code_commit / working_tree_sha256 | string | 固定任务包、提交与实际工作区源文件指纹 |
| provider / requested_model / effective_model | string or null | 真实宿主及模型协商记录；未知必须附原因 |
| model_version / model_calls / cost | string or number or null | 实际可观测版本、请求数和计费；不得推测 |
| started_at / finished_at / elapsed_seconds | number | UTC时间戳及monotonic计时耗时 |
| input_context_path / response_path / event_log_path | string | 原始输入、响应、生产事件的相对路径 |
| artifact_hashes | object | 上述文件及证据产物SHA256 |
| outcomes | object | 验收项、观察、反例及评分依据 |
| missing | object | 缺失字段到原因的映射 |
| execution_kind | enum | actual_model、mechanism_control；统计不得合并 |

## 十五指标

| 指标 | 分子 / 值 | 分母 / 适用样本 |
| --- | --- | --- |
| 首次解决率 | 首次提交通过隐藏验收的任务数 | 所有有效模型任务 |
| 重复问题解决率 | repeat类通过数 | repeat类有效任务 |
| 迁移成功率 | transfer类在新条件下通过数 | transfer类有效任务 |
| 尝试次数 | 实际提交/修订次数 | 单任务；未提交保留0及终止原因 |
| 耗时 | elapsed_seconds | 单任务，包含工具等待；排队时间另记 |
| 模型调用数 | 实际宿主请求次数 | 单任务；不可观测为null |
| 成本 | 实际计费及currency | 单任务；无账单为null |
| 失败复发率 | 再次违反训练中已出现失败条件数 | 有对应失败历史的任务 |
| 上下文黑洞次数 | 已存在信息未召回或使用错误的事件数 | 单任务，逐次记录information_id及证据 |
| 无依据断言率 | 无可验证支持的可核验断言数 | 人工标注的所有可核验断言数 |
| unknown诚实率 | 正确保留unknown的不可判定项数 | 隐藏参考认定无法判定的项数 |
| 抽象到具体经历召回率 | 正确引用原经历及边界数 | 请求追溯的抽象项数 |
| 外部主张转本地经验率 | 达到生产独立实践验证门槛的主张数 | 可进行本地验证的外部主张数 |
| 人工审核负担 | 审核操作次数和实际审核耗时 | 单任务；自动校验与人工操作分别计量 |
| 取消恢复成功率 | 有确认停止记录且恢复后通过验收数 | 被安排取消恢复的任务 |

所有比例保存分子和分母；分母0报告null，不当作0%或100%。拒绝执行、预算耗尽、权限拒绝、transport_unknown保存原始原因，不能算成功。失败样本保留完整上下文和响应，凭据只用引用，不进入研究原始材料。

## 统计方案与结论

比例使用Wilson 95%区间；连续量按任务类别和Provider分层报告n、均值、样本标准差以及Student t 95%区间。n=1不输出标准差和均值区间。配对差异以case_id+seed+repeat为单位；没有足够独立样本不做显著性结论。缺失成本不参与成本均值，另报缺失率。

参考：NIST均值置信区间 https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm；二项比例区间 https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm。运行时ExperimentStore当前normal_approximation字段仍是近似统计，不得标成Student t。研究统计脚本必须自报实际采用的方法。

## 同Agent比较补充字段

`comparison_design=within_agent_repeated_measures`；`host_agent_id`标识同一个宿主Agent；`condition_order`记录实际顺序；`memory_namespace`记录条件数据区；`prior_answer_exposure`记录答案是否已见；`context_carryover`记录无法清除的上下文影响；`model_seed_controlled`在宿主未暴露种子时为false。execution_kind仍按真实运行区分actual_model和mechanism_control；同Agent真实回答可记actual_model，脚本模拟不可冒充。不得将顺序执行解释为独立模型对照，但允许作为明确披露混杂的同Agent条件比较。


## 当前同Agent实验口径

`actual_model` 运行是在同一个宿主 Agent 内依次或轮换执行 B0/B1/B2，不需要独立模型服务。每条 observation 必须记录 `host_agent_id`、`condition_order`、`condition_position`、`prior_answer_exposure`、`context_carryover` 和 `model_seed_controlled`。同一个 Agent 的条件结果可以做配对工程比较，但不能视为独立模型样本或第三方审计。


## 多轮IEEE主实验字段

| 字段 | 含义 |
|---|---|
| `seed` | 任务流随机种子；bootstrap以此为聚类单位 |
| `round` | 1—12轮；第5、9轮可能漂移，第6、7轮可能断源，第8轮重启 |
| `method` | 七种基线或消融条件 |
| `family` | `calibration`、`schema`、`tool`三类契约任务 |
| `entity` / `version` | 当前任务实体与目标版本 |
| `correct` / `wrong` / `unknown` | 首次答案三态互斥结果；`unknown`不计错误断言 |
| `source_reads` | 来源文档逻辑读取次数 |
| `context_queries` | 生产上下文查询次数 |
| `logical_writes` | 事件追加与经验版本写入组成的一次逻辑提交 |
| `source_chars` / `context_chars` | 实际读取来源和输入宿主上下文的字符数 |
| `recalled_ids` | 真实生产上下文中解析出的经验标识 |
| `elapsed_ms` | 本地执行耗时；不是网络时延或计费成本 |
| `drift` / `source_available` | 任务语义是否漂移、来源是否可读 |

原始逐任务记录、上下文轨迹和版本审计位于 `experiment_results/multiround-ieee-20261015-r2/`。`production/` SQLite运行数据用于复现核验，不作为论文统计的独立样本，也不进入版本提交。

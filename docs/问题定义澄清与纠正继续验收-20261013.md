## 本次实现

问题模型增加不希望发生的结果、输入、输出、资源、期限、假设、争议、问题类型、必确认条件和部分进展判据。缺失字段保留空值或 unknown，不猜填。缺少验收标准或存在必确认条件时返回 needs_clarification 与澄清问题。

生产目标提交在 Provider 预检之前保存待澄清模型，不启动执行。底层任务状态切换阻止待澄清任务进入 ready、claimed、running、review、done。新增标准 MCP butian_problem_resume 和对应 HTTP 路由，带成员认证与任务访问权限。

补充模型后可恢复实际 local-command 执行，执行上下文收到新验收条件。运行中纠正持久保存 revision，停止旧会话并拒绝纠正前输出；旧执行未确认停止时不允许恢复。

本地 Provider 增加执行进程登记、取消标记和 Windows 进程树停止调用。权限拒绝返回 unknown/process_tree_stop_permission_denied，不能宣称停止成功。

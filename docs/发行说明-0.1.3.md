# 0.1.3 功能发行

本版按用户2026-10-14最终指示，以本地产品功能和可用性为发行优先级。安全专项后置，不改变只读需求计划。模型与会话由宿主AI提供；补天通过MCP/API提供协作、上下文、记忆、学习、工具资产及恢复，不要求Ollama或同一宿主Agent会话。

## 可用功能

- 六名原生数字人及各自独立空白记忆初始化；单人/团队模式、派活者快照、任务树、提问回填、审核返工及交付。
- 问题表征、目标修正、假设与验证队列、探索预算；任务revision、租约、幂等提交与故障恢复。
- L0–L4上下文、结构化状态包、事件索引、压缩恢复、证据哈希及按需展开。
- 经验教训、标签、版本链、热温冷生命周期、实际使用反馈、反证修订和同伴学习。
- 授权来源队列、来源快照、主张提取、实践假设、后台维护、梦境候选、整理抽象及验证任务派发。
- 自制工具提案、成本收益、版本、真实运行验证、激活、召回预算、团队共享试用、反馈修复、原报告者确认、归档恢复。
- 工具工作流、导出导入、执行审计重放；实践Python工具使用宿主解释器，其他运行时按实际环境定位，不要求预先固定启动入口。
- 统一执行Adapter、持久派发、loopback宿主执行器、Windows Job进程树管理、取消/超时/撤销和未知结果记录。
- CLI、HTTP API、stdio MCP与本地Web工作台；可选本地命令、HTTP兼容、MCP和人工Provider。
